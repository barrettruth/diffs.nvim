Diffs highlights the code inside unified diff hunks with Treesitter or Vim
syntax. It adds line backgrounds and intra-line highlights. It adjusts native
diff colors through 'winhighlight'.

Diff commands, repository review, file comparison, and conflict resolution are
available in diffs-collection.nvim:
    https://github.com/barrettruth/diffs-collection.nvim

==============================================================================
SETUP                                                     *diffs.nvim-setup*

Requirements: Neovim 0.12.0 or later. Treesitter parsers are optional.

Install with |vim.pack|: >lua
    vim.pack.add({ 'https://github.com/barrettruth/diffs.nvim' })
<
Set |g:diffs| before the plugin loads. No setup function is required.
Do not lazy load with `event`, `lazy`, `ft`, `config`, or `keys`.
Load your colorscheme before diffs.nvim.

Diffs attaches to `git` and `gitcommit` buffers by default. To attach to patch
files with the `diff` filetype: >lua
    vim.api.nvim_create_autocmd('FileType', {
      pattern = 'diff',
      callback = function(event)
        require('diffs').attach(event.buf)
      end,
    })
<

CONFIGURATION                            *diffs.nvim-configuration* *g:diffs*

Defaults: >lua
    vim.g.diffs = {
      debug = false,
      view = { prefix = true },
      highlights = {
        background = true,
        warn_max_lines = true,
        treesitter = { max_lines = 500 },
        vim = { max_lines = 200 },
        intra = { max_lines = 500 },
      },
      integrations = {},
    }
<
`debug`
    Set to `true` for debug messages. Set to a file path to write a log.

`view.prefix`
    Show unified diff prefixes. Set to `false` to conceal the prefixes.

`highlights.background`
    Apply background colors to added and removed lines.

`highlights.blend_alpha`
    Blend line backgrounds with the Normal background. The default is 0.6.
    Values must be between 0 and 1. Higher values retain more of the diff color.

`highlights.warn_max_lines`
    Show a warning when a hunk exceeds a configured line limit.

`highlights.treesitter.max_lines`
    Maximum hunk size for Treesitter syntax highlighting.

`highlights.vim`
    Configure Vim syntax fallback with `{ max_lines = N }`.
    Set to `false` to disable fallback. Set to `true` to use its default limit.

`highlights.intra.max_lines`
    Maximum hunk size for intra-line highlights.

All line limits must be at least 1. Large hunks retain line backgrounds.

'diffopt' controls intra-line highlighting: >vim
    set diffopt+=inline:word
<
Supported modes are `none`, `simple`, `char`, and `word`. Without an `inline:`
entry, diffs uses `simple`. Whitespace options in 'diffopt' also apply.

INTEGRATIONS                                       *diffs.nvim-integrations*

Enable integrations by name: >lua
    vim.g.diffs = {
      integrations = { 'fugitive', 'neogit', 'neojj', 'gitsigns', 'telescope' },
    }
<
Fugitive
    Attach to `fugitive` buffers.

Neogit
    Attach to `NeogitStatus`, `NeogitCommitView`, and `NeogitDiffView` buffers.
    Diffs renders intra-line colors in place of Neogit's inline groups.

neojj
    Attach to `NeojjStatus`, `NeojjCommitView`, and `NeojjDiffView` buffers.

Gitsigns
    Highlight unified diff previews and blame popups.

Committia
    Diff panes receive highlighting automatically.

Telescope
    Highlight diff buffers in Telescope previews.

LUA API                                                    *diffs.nvim-api*

Use `require('diffs')` to access the public API.

attach({bufnr}, {options})                               *diffs.nvim.attach()*
    Attach highlighting to a buffer.  Called automatically when the buffer's
    filetype matches `git`, `gitcommit`, or an enabled integration filetype.
    Direct calls work with any filetype.

    Parameters: ~
        {bufnr}  (integer, optional) Buffer number. Omit or use 0 for current.
        {options} (table, optional) ~
                 • {hunks} (function, optional) Receives the buffer number.
                   Returns |diffs.Hunk| tables in buffer order.
                 • {intra} (boolean, optional) Set false to disable intra-line
                   highlighting.

    Pass {options} to replace an attachment.  Without it, repeated calls do
    nothing.  The {hunks} callback runs on attachment and on redraw after edits
    or |diffs.nvim.refresh()|.

                                                                *diffs.Hunk*
    Hunk fields: ~
        {filename}       (string) Source filename.
        {start_line}     (integer) One-based hunk header line.  Use 0 when the
                         body starts on the first buffer line without a header.
        {lines}          (string[]) Diff body, including diff prefixes.
                         Element i is buffer line start_line + i (one-based).
                         Exclude display columns before the diff prefixes.
        {column_offset}  (integer, default: 0) Extra bytes before each prefix
                         in the displayed buffer.
        {prefix_width}   (integer, default: 1) Diff prefix width in bytes.
        {quote_width}    (integer, default: 0) Quote prefix width in bytes.
        {ft}             (string, optional) Vim syntax filetype.
        {lang}           (string, optional) Treesitter parser language.
        {header_start_line} (integer, optional) First file header line
                         (one-based).
        {header_lines}   (string[], optional) File header lines.
        {header_context} (string, optional) Code after the hunk header.
        {header_context_col} (integer, optional) Zero-based byte column of
                         {header_context}, excluding {column_offset}.

detach({bufnr})                                          *diffs.nvim.detach()*
    Stop highlighting the buffer and clear its highlights.

    Parameters: ~
        {bufnr}  (integer, optional) Buffer number. Omit or use 0 for current.

refresh({bufnr})                                        *diffs.nvim.refresh()*
    Refresh highlighting on the next redraw.  If supplied, the {hunks}
    callback runs again even when the buffer text is unchanged.

    Parameters: ~
        {bufnr}  (integer, optional) Buffer number. Omit or use 0 for current.

highlight_options()                          *diffs.nvim.highlight_options()*
    Initialize highlight groups and return {hide_prefix} and {highlights}.
    The {highlights.priorities} fields are {clear}, {syntax}, {line_bg},
    and {char_bg}.

diff_options()                                    *diffs.nvim.diff_options()*
    Return options from 'diffopt': {algorithm}, {linematch}, {inline}, and
    the whitespace flags {ignore_whitespace}, {ignore_whitespace_change},
    {ignore_whitespace_change_at_eol}, and {ignore_blank_lines}.
    Unset options are absent.  An absent {inline} means "simple".

compute_intra_hunks({lines})                *diffs.nvim.compute_intra_hunks()*
    Return {add_spans} and {del_spans} using 'diffopt', or nil when no spans apply.
    {lines} contains diff body lines with one prefix byte per line.
    Each span has a one-based {line} index into {lines}, and one-based byte
    columns {col_start} and {col_end} after the prefix.  {col_end} is exclusive.

whitespace_only_lines({lines})            *diffs.nvim.whitespace_only_lines()*
    Return a table of one-based line indexes with value true for changes
    ignored by the whitespace options in 'diffopt'.  {lines} has the same
    format as |diffs.nvim.compute_intra_hunks()|.

HIGHLIGHT GROUPS                                     *diffs.nvim-highlights*

Diffs derives colors from Normal, DiffAdd, DiffDelete, DiffChange, and DiffText.
It updates its groups after ColorScheme events.

    DiffsClear          Base text color
    DiffsAdd            Added line background
    DiffsDelete         Removed line background
    DiffsAddText        Changed text on added lines
    DiffsDeleteText     Changed text on removed lines
    DiffsDiffAdd        Native diff added line background
    DiffsDiffDelete     Native diff deleted line colors
    DiffsDiffChange     Native diff changed line background
    DiffsDiffText       Native diff changed text background

                                                    *DiffsHighlights*
diffs.nvim triggers `User DiffsHighlights` after each highlight update, including
initialization and |ColorScheme| changes.  Register this autocmd before loading
diffs.nvim to apply your colors after each update: >lua
    vim.api.nvim_create_autocmd('User', {
      pattern = 'DiffsHighlights',
      group = vim.api.nvim_create_augroup('my_diffs_highlights', { clear = true }),
      callback = function()
        vim.api.nvim_set_hl(0, 'DiffsAdd', { bg = '#2e4a3a' })
        vim.api.nvim_set_hl(0, 'DiffsDiffDelete', { link = 'DiffDelete' })
      end,
    })
<
==============================================================================
LIMITATIONS                                         *diffs.nvim-limitations*

Treesitter parses each hunk separately. Hunks that start or end inside an
expression can have incomplete syntax highlighting.

Vim syntax fallback runs after redraw. A new hunk can appear without syntax
colors for one frame. Language parsers and queries load on first use.
